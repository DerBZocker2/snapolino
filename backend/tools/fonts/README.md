# Fonts fuer generate_presets.py

Diese TTF-Dateien sind nicht im Repo (Groesse, reine Build-Zeit-Abhaengigkeit
fuer `../generate_presets.py`, kein Laufzeit-Bestandteil von Box oder
Backend). Vor dem Ausfuehren des Generators einmalig laden:

```
./download_fonts.sh
```

Alle Fonts sind freie Google Fonts unter der SIL Open Font License:
Playfair Display, Poppins, Pacifico, Baloo 2, Bebas Neue, Caveat.
